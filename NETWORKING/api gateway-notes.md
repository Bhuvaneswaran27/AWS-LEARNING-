# Amazon API Gateway Notes

## What is Amazon API Gateway?
Amazon API Gateway is a fully managed service used to create, publish, secure, monitor, and manage APIs.

## Features
- REST APIs
- HTTP APIs
- WebSocket APIs
- Authentication using IAM and Cognito
- Request throttling
- Monitoring with CloudWatch

## Benefits
- Serverless integration
- Automatic scaling
- Secure API management
- Low operational overhead
