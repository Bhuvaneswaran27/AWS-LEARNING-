# AWS IAM Notes

## What is IAM?
AWS Identity and Access Management (IAM) is a service used to securely manage access to AWS resources.

## IAM Components
- Users
- Groups
- Roles
- Policies

## Types of Policies
- AWS Managed Policies
- Customer Managed Policies
- Inline Policies

## Features
- Multi-Factor Authentication (MFA)
- Password Policy
- Access Keys
- Roles for AWS Services
- Temporary Security Credentials

## Benefits
- Secure access management
- Fine-grained permissions
- Centralized user management
- Supports least privilege principle
