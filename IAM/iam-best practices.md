# AWS IAM Best Practices

1. Enable Multi-Factor Authentication (MFA).
2. Follow the principle of least privilege.
3. Avoid using the root account for daily tasks.
4. Create IAM groups to manage permissions.
5. Use IAM roles instead of sharing access keys.
6. Rotate access keys regularly.
7. Use strong password policies.
8. Review IAM permissions periodically.
9. Remove unused users and credentials.
10. Monitor IAM activity with AWS CloudTrail.
