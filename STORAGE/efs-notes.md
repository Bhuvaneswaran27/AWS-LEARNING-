# Amazon EFS Notes

## What is Amazon EFS?
Amazon Elastic File System (EFS) is a fully managed, scalable network file system for Linux-based workloads.

## Features
- Shared file storage
- Automatic scaling
- Multi-AZ access
- NFS protocol
- High availability

## Benefits
- Multiple EC2 instances can access the same file system
- Fully managed
- Durable and elastic
