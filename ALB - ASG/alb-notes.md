# Elastic Load Balancer (ELB) Notes

## What is ELB?
Elastic Load Balancer (ELB) automatically distributes incoming application traffic across multiple EC2 instances.

## Types of ELB
1. Application Load Balancer (ALB)
2. Network Load Balancer (NLB)
3. Gateway Load Balancer (GWLB)

## Benefits
- High Availability
- Fault Tolerance
- Health Checks
- SSL/TLS Termination
- Automatic Traffic Distribution

## Components
- Listeners
- Target Groups
- Health Checks
- Availability Zones
